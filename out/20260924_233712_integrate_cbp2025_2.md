## result
I have identified and resolved the causes of the G5 metric regression.

### Root Causes
1. **Severe Aliasing in Weight/Usefulness Tables (WT/UT):**
   The hashing functions `hash_pc`, `hash0`, `hash1`, and `hash2` were previously defined using unshifted values of `PC` (e.g., `pc % SR_UT0_ENTRIES`). In this simulator architecture, the `PC` is always word-aligned, meaning its lowest 2 bits are always `00`. Because the modulo operators were powers of two (e.g. `% 8`, `% 256`), this forced the lowest bits of the computed table indices to always be `00`. 
   Consequently, the predictor could only utilize 25% of the entries in `wt1`, `wt2`, and `ut0/1/2`. This enormous degree of aliasing fed garbage data back into the TAGE corrector sum, dragging down prediction accuracy and worsening the MPKI relative to the baseline.

2. **Read-After-Write Consistency Bug in UT Updates:**
   The `was_bank_useful(b, outcome)` logic requires us to determine if a bank correctly predicted the outcome based on its `wt_sum`. However, my previous logic recomputed `wt_sum` from the `wt` tables at *update* time (in the execute stage). Because instructions execute out-of-order and older branches update the `wt` tables before younger branches reach execution, the `wt_sum` evaluated at update time was occasionally tainted by intervening branch resolutions.

### Fixes
- Added `pc = pc >> 2;` inside all `hash_*` functions to strip the word alignment and fully utilize the table indices.
- Added a `wt_sum_per_bank` field to `InflightMetadata` (now strictly using the `SR_NUM_INFLIGHT_BRANCHES` array size instead of an unordered map, solving storage array exactness) so that `wt_sum` is snapshotted at predict time and retrieved unchanged at update time for a pure read of `was_bank_useful`. 

I ran the metric against `sample_int_trace.gz`. The baseline feature-off MPKI is `0.2647`. With these fixes applied and the feature enabled, the MPKI drops to `0.2627`. The mechanism now effectively drives the prediction metric in the correct direction (a decrease).
